POST/model/<name>

Train + evaluate the model; returns MSE / MAE / DA / R² / time.

add persistent-homology features
trains on call — a few seconds (longer with small stride / big resolution)
POST/pipeline/run

Unified pipeline: data → preprocessing chain → model train+eval. Returns metrics + timing breakdown.

preprocessing pipeline (in order)
params is JSON — edit inline or leave the default for the chosen node
empty preprocessing list = raw OHLCV (no PH)
GET/pipelines

List recent pipeline jobs (running + finished, newest first). Click an id to inspect; ✕ kills a running job.

GET/pipeline/<id>

Full job details: submitted body + status + result/error + elapsed time.

POST/pipeline/<id>/kill

Terminate the worker subprocess for a running job. No-op (returns current state) for finished jobs.
